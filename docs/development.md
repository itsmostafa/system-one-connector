# Development

`evaluate` is a single Go binary. The code lives in [`cmd/evaluate/`](../cmd/evaluate/), and [`cmd/evaluate/CLAUDE.md`](../cmd/evaluate/CLAUDE.md) explains what each file holds and which strings must stay in sync.

## Tasks

The repo uses [Task](https://taskfile.dev):

| Command | What it does |
|---|---|
| `task build` | Builds `./evaluate` (gitignored) |
| `task check` | Runs gofmt, `go vet`, and the tests with `-race` |
| `task test` | Runs the tests only |
| `task fmt` | Formats Go code |
| `task inspect` | Builds, then opens the MCP Inspector against the local server |
| `task install` | Installs into `GOBIN` |

Run `task check` before opening a pull request.

## Commits and releases

Commit subjects follow [Conventional Commits](https://www.conventionalcommits.org/). [release-please](https://github.com/googleapis/release-please) reads them to pick the next version:

| Prefix | Version bump |
|---|---|
| `feat` | Minor |
| `fix` | Patch |
| `!` (breaking) | Minor while the version is below 1.0 |
| `docs`, `test`, `chore` | None |

Scopes in use: `tools`, `setup`, `client`, `cli`, `readme`.

`CHANGELOG.md` and `.release-please-manifest.json` are generated by the release workflow. Don't edit them by hand.
